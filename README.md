


## Uruchomienie lokalne

### 1. Sklonuj repozytorium

```
git clone https://github.com/DominikLesniowski/Cookies_ING.git
cd Cookies_ING
```

### 2. Utwórz i aktywuj wirtualne środowisko

```
python3 -m venv venv
```

- **macOS / Linux:**
  ```
  source venv/bin/activate
  ```
- **Windows:**
  ```
  venv\Scripts\activate
  ```
